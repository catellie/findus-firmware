Set up Findus Household

A private Google Sheet, a generic Findus, and no household secrets in the firmware.

1. Copy the household Sheet

Create your private copy, then use Findus > Set up Findus to initialize and deploy it.

Copy the Findus Household Sheet

2. Install Findus

Choose by the exact product. Disconnect other ESP32 devices before installing. These two devices use different firmware even though both contain an ESP32-S3.

Round 1.28-inch Findus

sp-esp32-s3-1.28-box

Use a desktop browser that supports Web Serial. Allow this page to use the connected USB device.

White Waveshare 2.16-inch AMOLED

waveshare/esp32-s3-touch-amoled-2.16

Use a desktop browser that supports Web Serial. Allow this page to use the connected USB device.

3. Connect and enroll

  1. Wait until the newly installed device makes a Findus-XXXX Wi-Fi network. Stay on your normal internet connection for now.
  2. Return to Findus > Set up Findus in the Sheet. Enter the child or owner's name, create the 30-minute enrollment bundle, and copy it.
  3. Join Findus-XXXX, then enter the household Wi-Fi password.
  4. Paste the complete enrollment bundle copied from the Sheet.
  5. Wait while Findus registers and builds its local language pack.
